1) Пояснення

Нуль це маркер, а не значення. 0 у salary_usd означає «немає зарплати, бо не працевлаштований». Якщо його залишити, нулі потрапляють у розрахунок як реальні зарплати і тягнуть середнє та медіану вниз.
Питання визначає базу. «Яка середня початкова зарплата?» стосується тих, у кого вона є. Тому рахуємо лише по status == "Placed" (або salary_usd > 0). Краще фільтрувати за status: це явна ознака, і вона не зламається, якщо колись з'явиться справжня нульова виплата або пропуск.
Показуйте і частку працевлаштованих. Середнє по працевлаштованих нічого не каже про те, скільки студентів узагалі знайшли роботу. Це окремий показник, його варто виводити поруч, щоб не вводити читача в оману.

2) Код pandas

python
import pandas as pd
from io import StringIO

csv = """student_id,status,salary_usd
S1,Placed,70000
S2,Not Placed,0
S3,Placed,90000
S4,Not Placed,0
S5,Placed,80000
S6,Placed,100000"""

df = pd.read_csv(StringIO(csv))

# Неправильно: нулі входять у розрахунок
naive_mean = df["salary_usd"].mean()
naive_median = df["salary_usd"].median()

# Правильно: лише працевлаштовані
placed = df[df["status"] == "Placed"]
mean_salary = placed["salary_usd"].mean()
median_salary = placed["salary_usd"].median()

# Частка працевлаштованих
placement_rate = (df["status"] == "Placed").mean()

print(f"Наївне середнє:   {naive_mean:.2f}")
print(f"Наївна медіана:   {naive_median:.2f}")
print(f"Середнє (Placed): {mean_salary:.2f}")
print(f"Медіана (Placed): {median_salary:.2f}")
print(f"Частка Placed:    {placement_rate:.1%}")

# Альтернатива: замінити 0 на NaN, pandas ігнорує NaN автоматично
df["salary_clean"] = df["salary_usd"].replace(0, pd.NA)
print(df["salary_clean"].astype("float").mean())
